# The Linen Leaf — Multi-page Website

A responsive, modern website for **The Linen Leaf by Simran**, built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
- Google Fonts

## Pages
- `index.html` — Home with full-screen video background
- `about.html` — Brand introduction, philosophy and care guidance
- `collection.html` — Product collection with JavaScript filters
- `contact.html` — Contact details and WhatsApp enquiry form

## Assets
The `assets` folder contains:
- Your supplied logo
- Your supplied hero video
- Product images extracted from the supplied catalogue PPTX

## Run locally
1. Unzip the folder.
2. Open the folder in VS Code.
3. Recommended: install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

The site also works by opening `index.html` directly in a browser, although a local server is recommended for video/media behaviour.

## Notes
- Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is useful for the full styling.
- The contact form does not require a backend. It prepares the user's enquiry and opens WhatsApp.
- Replace the WhatsApp number, Instagram URL, text, or product images in the HTML if the business details change.
